## إصلاحات إضافية

- مزامنة تاريخ الأيام الكامل، وإظهار فشل أي يوم بدل إعلان نجاح القسم كله.
- إزالة تعريفات المزامنة المكررة التي كانت تخفي تعريفات أقدم.
- التحقق من بنية النسخة الاحتياطية قبل حذف البيانات، والتراجع عند فشل التخزين.
- منع السحب المباشر أثناء استعادة معلقة، وتحديد انتظار الاستعادة بـ15 ثانية مع بقاء سجل إعادة المحاولة. اكتمال عملية متأخرة لا يطمس التعديلات المحلية اللاحقة.
- اختبارات ثابتة للفئات على أصل HTTP، وعزل خدمات الشبكة الخارجية في اختبارات القراءة، وتحديث بدائل Firestore لتعكس معرّفات المستندات.
- إضافة فحص رجعي إلى GitHub Actions قبل النشر، وتثبيت إصدار Playwright، وتجهيز ملفات الموقع فقط للنشر.
- تحديث مخزن تطبيق الويب إلى `mufakkirati-v132`، وإضافة `data-core.js` إلى الملفات المتاحة دون اتصال.

## التحقق والحدود

التشغيل الكامل: `npm test`. اختبارات المتصفح تستخدم Chromium؛ اختبارات المزامنة تحقن بديل Firestore وتختبر فشل القراءة والكتابة وتأخرها، وليست اختبارًا على قاعدة بيانات الإنتاج. يوجد اختبار مستقل لفتح التطبيق وحفظه دون اتصال عبر عامل الخدمة الحقيقي.

لا تعيد هذه الإصلاحات بيانات فُقدت سابقًا ولم تبقَ منها نسخة محلية أو سحابية أو احتياطية. التخزين القديم غير المنسوب لحساب يُرحّل إلى الحساب الأول الذي يستقبل بيانات الضيف؛ لا توجد معلومة تاريخية تسمح باستنتاج مالك مختلف. التنبيهات تتطلب بقاء التطبيق قادرًا على التشغيل؛ أُضيف توضيح لذلك، ولم تُنشأ خدمة دفع خلفية. قواعد صلاحيات Firebase خارج هذا المستودع ولم تُعدّل.
