# Family Integration Implementation Plan
> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.
**Goal:** Make family management reliable and integrated with the existing planner and finance.
**Architecture:** Keep existing finance storage and planner canonical tasks. Add guarded family mutations and per-record member merge within settings. Migrate legacy events with stable IDs, retaining source rows for retry safety.
**Tech Stack:** Vanilla JS, localStorage/Firestore, Node tests and Playwright.
**Spec:** docs/superpowers/specs/2026-10-23-family.md
## Global Constraints
- Preserve financial calculations and all existing records.
- No separate household accounts, paid services, or live-user test data.
## Review Focus
- Offline concurrent member adds and archive against stale devices: retain both records and archives.
- Full storage during edits: preserve draft and original data, allow retry.
- Legacy event retry/move/delete: never recreate an already migrated occurrence.
- Shopping expense repeated click or stale device: stable transaction identity and no automatic debit on completion.
- Narrow RTL screens and long names: no overflow or hidden actions.
