> **For agentic workers:** Use superpowers:subagent-driven-development task-by-task; preserve test evidence and review each deliverable.

**Goal:** Resolve all eleven demonstrated learning defects and simplify the audited workflows without changing finance.
**Architecture:** Narrow changes to existing learning/calendar functions and styles in index.html; retain current data identities and backward compatibility. Browser regressions exercise real application code with synthetic storage and mocked Google transport.

## Global Constraints
- Do not modify personal data or delete schedules based on matching names.
- Preserve occurrence outcomes, exceptions, existing event bindings and independent future changes.
- Finance is frozen; run whole-suite regressions before release.
- Arabic RTL, both themes, 320/390/820/1366 widths; support failed font loading.
- Google verification is synthetic, never claim real account/device verification.
- No automatic historical term reassignment or new dependencies.

- Missing historical term IDs and independent/custom bounds (Task 2).
- Parent refresh and draft dismissal through all close mechanisms (Task 3).
- Context filters and fallback fonts on narrow screens (Task 3).
